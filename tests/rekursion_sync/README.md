# Rekursion Thor Parity Test Suite

This directory contains integration test suites designed to verify semantic and syntactic compliance between this Odin-based Thor implementation and the canonical **rekursion/thor** specification at `/Users/prakash/Documents/projects/rekursion/lang/thor/`.

## Test Matrix

| Test Fixture | Purpose & Scope |
|---|---|
| [source.thor](file:///Users/prakash/github/Odin/tests/rekursion_sync/source.thor) | Authoritative reference source file synced from `rekursion/lang/thor/source.thor`, exercising pure functions (`func`), DOP structs, tagged unions, bit sets, and distinct types. |
| [test_rekursion_parity.thor](file:///Users/prakash/github/Odin/tests/rekursion_sync/test_rekursion_parity.thor) | Complete test suite validating math algorithms, pure transformations, and memory-safe functions using Thor semantics. |
| [test_c_ingest_compat.thor](file:///Users/prakash/github/Odin/tests/rekursion_sync/test_c_ingest_compat.thor) | Tests bindings and data structures generated by the Thor C Header Ingestor (`c_ingest.odin`). |

## How to Run

Run with the Thor driver:
```sh
thor check tests/rekursion_sync/source.thor -file
thor run tests/rekursion_sync/test_rekursion_parity.thor -file
thor run tests/rekursion_sync/test_c_ingest_compat.thor -file
```

Or execute the automated Go synchronization engine:
```sh
go run scripts/sync_rekursion_thor.go
```
